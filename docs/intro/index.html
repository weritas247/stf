01 — 인벤토리

디바이스 선반

연결된 기기가 실시간으로 나타나고, 상태(온라인·사용중·예약·오프라인)로 필터됩니다. 카드를 눌러 원격 제어 콘솔을 여세요.

02 — 원격 제어

Pixel 7 Pro 제어 중

선반에서 고른 기기의 화면·네비게이션 버튼이 브라우저에 그대로. adb connect 한 줄이면 로컬 IDE에서도 같은 기기를 잡습니다. 아래 셸에 명령을 쳐보세요.

14:5278%
7
Pixel 7 Pro
Android 13 · 실시간 미러
$adb connect 127.0.0.1:5555
adb shell — pixel-7-pro
$

데모 셸입니다 — help · adb devices · getprop · pm list · screencap · clear 를 지원합니다.

05 — 시작

로컬에서 30초 만에

macOS 기준. RethinkDB만 떠 있으면 stf local 한 방에 모든 프로세스가 뜹니다.

프로덕션 배포·systemd 유닛 구성은 저장소의 doc/DEPLOYMENT.md 참고. 에뮬레이터(BlueStacks 등)는 adb connect 127.0.0.1:<port> 로 붙이면 선반에 그대로 올라옵니다.
